How To Import/Add Candidates

  1. In Excel or Google Sheets, make sure your columns are: name, role, dept, source, stage
  2. Save / download the file as CSV.
  3. Choose the file below and click Import Candidates.

How To Import HR Data For Source Effectiveness

  1. In Excel or Google Sheets, make sure your columns include: RecruitmentSource, EngagementSurvey, Termd
  2. RecruitmentSource is the hiring source name, EngagementSurvey is a score from 0–5, and Termd is 1 if the employee was terminated or 0 if still employed.
  3. Save / download the file as CSV.
  4. Choose the file below and click Import HR Data.
